# Aurox Cloud VPS (GitHub Codespaces + Browser Desktop)

Your repository is configured with an official **Debian 12 Linux Cloud VPS + Full Browser Desktop GUI** inside GitHub.

## How to Launch Your VPS in 3 Clicks
1. Open your repository page: **https://github.com/omarmonna31-sketch/Website-Project**
2. Click the green **`<> Code`** button → switch to the **`Codespaces`** tab → click **`Create codespace on main`**.
3. Wait ~1–2 minutes on the first boot while Linux, the Desktop GUI, and Firefox install automatically.

## How to Open the Graphical Linux Desktop in Your Browser
1. Inside the Codespace window, click the **`PORTS`** tab (bottom panel next to `TERMINAL`).
2. Find port **`6080`** (*Aurox Linux Desktop GUI (noVNC)*) and click the **Globe icon (`Open in Browser`)**.
3. Click **`Connect`** and enter the Desktop password:
   - **Password:** `aurox123`
4. **Right-click anywhere on the desktop wallpaper** to open the **Aurox Cloud VPS Menu** (*Firefox Web Browser*, *Terminal*, *File Manager*, *Text Editor*, *Task Manager*).

## Pre-Installed Tools
- **OS:** Debian 12 (Bookworm) Linux with full `sudo` root access
- **Desktop GUI:** Fluxbox + TigerVNC + noVNC (`1920x1080`)
- **Apps & Runtimes:** Firefox ESR Browser, Tilix Terminal, Nautilus File Manager, Python 3 + pip, Node.js + npm, `tmux`, `htop`, `git`, `curl`, `wget`
